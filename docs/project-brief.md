# Project Brief

## プロジェクト概要

RepairctのInstagram導線型LPを制作する。Repairctは住宅内装リペア業で、LPはInstagramプロフィールから訪れた閲覧者をInstagram DMへ誘導するために使う。

## 目的

- Repairctの世界観と業種を短時間で伝える
- 住宅内装リペアの相談範囲を分かりやすく見せる
- 若い職人の感性・対応力・信頼感を伝える
- Instagram DMでの相談を主導線にする

## ターゲット

- 住宅内装の傷や劣化を相談したい個人または関係者
- 相模原、神奈川、東京、周辺県でリペア相談を検討している人
- InstagramからRepairctを知り、雰囲気や相談しやすさを確認したい人

## LPの方向性

- 黒基調のモノトーン
- 透明感、薄い光、細い罫線を使ったスタイリッシュな印象
- 若さを軽さではなく、感性・柔軟性・丁寧さとして伝える
- 売り込みすぎず、短く洗練されたコピーにする
